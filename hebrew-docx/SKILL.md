# מסמכי Word בעברית, מימין לשמאל

הסקיל הזה מייצר קבצי Word בעברית שנפתחים נכון ב-Word, ב-Pages וב-Google Docs: פסקאות מימין לשמאל, טבלאות שהעמודה הראשונה שלהן מימין, פיסוק בצד הנכון, והדגשה וגודל גופן שעובדים גם על טקסט עברי.

## למה צריך אותו

Word מניח כברירת מחדל שכל פסקה נכתבת משמאל לימין. במסמך עברי צריך לסמן כיוון ימין לשמאל בחמישה מקומות: ברירת המחדל של המסמך, כל פסקה, כל קטע טקסט, הגדרת העמוד וכל טבלה. בנוסף, Word לוקח את הגופן, ההדגשה והגודל של טקסט עברי משדות נפרדים ("complex script") שספריות כמו python-docx לא כותבות. מסמך שנבנה בלי כל אלה נפתח עם טבלאות הפוכות וטקסט עברי בגודל הלא נכון.

הסקריפט `scripts/hebrew_docx.py` עושה את כל זה, ונבדק ב-Word. לכן במסמך שרובו עברית: תמיד דרך הסקריפט. לא לבנות docx ידנית (python-docx או docx-js) ולא דרך pandoc.

## מתי להשתמש

- כל בקשה למסמך בעברית כקובץ: Word, docx, "מסמך", "קובץ להורדה", אפיון, דוח, מכתב, הצעה, טבלה.
- בקשה לתקן קובץ Word בעברית שיצא הפוך או מבולגן.

## איך

1. כתוב את התוכן כ-Markdown לקובץ `.md` (התחביר הנתמך בהמשך).
2. הרץ את הסקריפט מתוך תיקיית הסקיל הזה:
   ```
   python3 <skill-dir>/scripts/hebrew_docx.py input.md /mnt/user-data/outputs/<name>.docx
   ```
   אם python-docx חסר: `pip install python-docx` והרץ שוב.
3. מסור את קובץ ה-docx למשתמש.
4. אם המשתמש ביקש PDF: המר את ה-docx עם
   `soffice --headless --convert-to pdf --outdir /mnt/user-data/outputs <file>.docx`.
   אם soffice לא זמין, מסור את ה-docx והסבר שאפשר לשמור אותו כ-PDF מתוך Word או Pages.

תיקון קובץ Word קיים שיצא הפוך:

```
python3 <skill-dir>/scripts/hebrew_docx.py --fix input.docx /mnt/user-data/outputs/<name>-fixed.docx
```

התיקון מסמן כיוון ימין לשמאל בכל המסמך, כולל טבלאות, כותרות עליונות ותחתונות, ומשאיר את התוכן והעיצוב כמו שהם.

## Markdown נתמך

- כותרות: `#`, `##`, `###` (הכותרת הראשית ממורכזת)
- פסקאות, `**מודגש**`, `*נטוי*`
- רשימות: `- פריט` ו-`1. פריט`, ורשימה מקוננת עם שני רווחים לכל רמה
- טבלאות: `| עמודה | עמודה |` עם שורת `|---|---|` מתחת לשורת הכותרת
- ציטוט: `> טקסט`
- בלוק קוד בין שלושה גרשיים הפוכים (מוצג משמאל לימין)
- קישור `[טקסט](כתובת)` מוצג כטקסט, והכתובת בסוגריים אחריו
- קו מפריד (`---`) לא מודפס

## כללים

- בטבלה, העמודה הראשונה ב-Markdown היא העמודה הימנית במסמך. כתוב את העמודות בסדר הקריאה הטבעי, מימין לשמאל.
- טווח עם סימנים, כמו אחוזים או מטבע, עדיף לכתוב במילים: "5% עד 15%". הסקריפט מגן גם על "5%-15%" שלא יתהפך, אבל הניסוח במילים טבעי יותר בעברית.
- אל תכתוב בתוך המסמך תווי כיווניות בלתי נראים (כמו אלה שמשמשים בצ'אט). הסקריפט מנקה אותם בכל מקרה.
- הגופן הוא Arial, שקיים ב-Mac, ב-Windows וב-Google Docs ויש בו עברית. אל תחליף לגופן שאין בו עברית.
- אם משהו נראה לא תקין, הרץ `python3 <skill-dir>/scripts/hebrew_docx.py --self-test` כדי לבדוק את הסקריפט בסביבה.
